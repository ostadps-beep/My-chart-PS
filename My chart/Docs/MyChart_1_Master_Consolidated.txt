[FINAL] Chart First. Data Is Pure. Single Theme System. Single Color
System. Module Isolation. Contract Communication. Performance First.
Interaction Consistency.

Product identity: Analysis First. Pillars: Clean, Fast, Analytical,
Predictable, Professional. Style: CAD-inspired, professional-terminal
inspired, low noise, high information density, minimal UI.

Core identity features: - Context Toolbar - Advanced Analysis
Crosshair - Dual Price Marker - Smart HUD - Optional Navigator -
Professional Axis - CAD-style Interaction

Visual priority: Price > Analysis > Tools > UI.

[FINAL] - Data never contains visual information. - Renderer owns
appearance. - One global Theme System and one global Color System. - UI
never directly accesses a Data Source. - Renderer never accesses
Database/Network/API. - Data never depends on UI. - Modules communicate
through Contracts. - Chart Engine is independent of specific
providers. - Interaction must remain consistent and predictable. -
Maximum chart space is preferred. - Important state must be
serializable. - State-changing user actions are Command-based and
Undo-aware. - Performance has priority over visual effects. - Common
daily operations should require no more than two clicks.

[FINAL] Projects: ChartMy.Core, ChartMy.Data, ChartMy.Rendering,
ChartMy.Interaction, ChartMy.Drawing, ChartMy.Indicators, ChartMy.UI,
ChartMy.Infrastructure, ChartMy.App.

Layers: Data, Rendering, Interaction, Drawing, UI, Infrastructure.
Dependency: UI -> Services/Contracts -> Core; Core never depends on UI.
Foundation concepts: Contracts, Models, Services, Managers, Events,
Commands, Renderers, Controls.

============================================================ 04 — CANDLE
MODEL ============================================================

[FINAL] Canonical Candle: Timestamp, Open, High, Low, Close, Volume.
Forbidden: Color, Brush, Theme, Style, Visual State. Rule: Data !=
Appearance; appearance comes from Renderer/Theme/Color.

============================================================ 05 — DATA
LAYER ============================================================

[FINAL] Architecture: ChartCore -> MarketDataBus -> Data Layer.

Components: SymbolManager, TimeframeManager, DataProviderManager,
DataCacheManager, HistoryManager, TickManager, AggregationEngine,
DataStorage.

IDataProvider: Connect, Disconnect, GetHistory, SubscribeTicks,
UnsubscribeTicks, GetSymbols, GetTimeframes.

Providers: CSV, MetaTrader, REST API, WebSocket, Replay, Custom.
Provider Manager: Load, Switch, Reconnect, Health Monitor, Failover.

V1 Provider: MetaTrader Provider. V1 path: MetaTrader -> EA ->
Socket/TCP/Pipe -> MetaTraderProvider -> MarketDataBus -> ChartMy.1.
ChartMy.1 is NOT dependent on MetaTrader; MetaTrader is only V1
provider.

Cache: Memory + Disk. Active memory: M1, M5, M15, M30, H1, H4, D1. Disk:
SQLite. Logical tables: Symbols, Candles, Ticks, IndicatorsCache,
Layouts.

HistoryManager: Download, Update, Validate, Merge, Gap Detection,
Repair. TickManager: Receive, Filter, Distribute, Tick Buffer.
Aggregation: Tick -> M1 -> M5 -> M15 -> H1 -> H4 -> D1.

MarketDataBus events: TickReceived, CandleUpdated, CandleClosed,
NewSymbol, NewTimeframe, HistoryLoaded, ProviderChanged.

SymbolManager: Registry, Normalization, Search, Groups, Favorites.
Groups: Forex, Crypto, Indices, Stocks, Commodities. Timeframes: Tick,
M1, M5, M15, M30, H1, H4, D1, W1, MN1.

Replay Engine: Backtest, Market Replay, Training. Sources: CSV,
Database, Provider. Offline: if Provider disconnects, Cache + Database
continue operation. Pipeline: Provider -> Validation -> Normalization ->
Cache -> Storage -> MarketDataBus -> Chart Engine. Future: Broker
Gateway, Multi Provider, Data Merge, Cloud Sync, Distributed Cache.

============================================================ 06 — DATA
VALIDATION ============================================================

[FINAL] Validation, Normalization, Duplicate detection, Invalid OHLC
detection, Missing Bars, Time Gaps, Corrupted Records, Gap Detection,
Repair Logic. Dependency: Data Layer.

[FINAL] Components: Visible Range, Zoom Engine, Pan Engine, Coordinate
Converter, Render Window. Rules: Smooth Zoom, Pixel Accurate Rendering,
Infinite Scroll Capability, Latest Candle Lock optional. Primary
interaction: Wheel = Zoom; Ctrl+Wheel = Precision Zoom; Middle Drag =
Pan.

[FINAL] ChartRenderer, LayerRenderer, Render Pipeline, Invalidation,
Performance controls. Renderer must not perform network/database/API
operations. Layer order: Background, Grid, Candle, Indicator, Drawing,
Selection, Crosshair, HUD, Tooltip, Overlay.

============================================================ 09 — CANDLE
RENDERER ============================================================

[FINAL] Supports OHLC, Hollow Candles, Bull/Bear Style, Selection State.
Appearance comes from centralized Theme/Color/Renderer systems.

============================================================ 10 — AXIS
SYSTEM ============================================================

[FINAL] Price Axis: right default, left optional, fixed width, separate
axis area, quiet/low-contrast presentation, right-aligned labels,
monospaced labels, smart density, collision avoidance, no overlap. Time
Axis: bottom default. Scale modes: Auto, Manual, Log, Percentage.

Axis behavior: dynamic label density, frozen axis during pan where
applicable, realtime update, auto-scale indicator, manual-scale lock
indicator, log badge.

Grid: major price labels connect to grid; minor labels do not require
grid. Current price: always visible; horizontal thin dashed line (~40%
opacity); axis-attached rounded/capsule marker; bull/bear color; price;
optional countdown. Crosshair price label remains above current-price
marker layer.

Dual Marker System: 1. Current Market Price Marker 2. Crosshair Analysis
Price Marker

Axis identity: Minimal Professional, quiet axis, strong current-price
marker, analysis-oriented, dual marker enabled.

[FINAL] Mode 1 Cursor: Price, Time. Mode 2 Analysis: Price Difference,
Point Difference, Pip Difference, Time Difference, Candle Count,
Percentage Change. Mode 3 Data Inspector: Date, Time, Open, High, Low,
Close, Volume. Mode 4 Magnet: Open, High, Low, Close. Crosshair is a
complete analysis system, not only a cursor.

============================================================ 12 —
INTERACTION ============================================================

[FINAL] Each input has one primary behavior. Wheel=Zoom;
Ctrl+Wheel=Precision Zoom; Middle+Drag=Pan; Left Click=Select; Double
Click Object=Properties/Tool Settings; Right Click=Context Menu;
Space+Drag=Temporary Pan; Shift+Click=Multi Select; Esc=Cancel Tool;
Enter=Finish Drawing; Home=Go To Latest Candle.

Consistency: Wheel always Zoom; Middle always Pan; Right Click always
Context Menu; Esc always Cancel. Common operations <=2 clicks.

Context menu is context-sensitive: Chart:
navigation/crosshair/drawing/indicator/chart options/reset. Drawing
object: edit/lock/clone/delete/object settings. Exact exhaustive
right-click command inventory is not separately frozen.

============================================================ 13 —
TOOLBAR ============================================================

[FINAL] Top: Symbol, Timeframe, Chart Type, Indicators, Templates,
Layout, Settings. Left: Cursor, Crosshair, TrendLine, Rectangle, Arrow,
Text, Fibonacci, Measure. Compact, modular, chart-space-first.

[FINAL] Selection/context controls: Color, Width, Opacity, Style,
Template, Lock, Clone, Delete. Purpose: change tool/object properties
without opening separate windows. Core identity feature.

============================================================ 15 — HUD

[FINAL] HUD = informational Analysis Overlay. Default: Visible, Compact,
Adaptive, top-left inside chart, mouse transparent, non-interactive, no
selection, theme controlled, approximately 75% opacity, no automatic
hide in the detailed final decision.

Information: Symbol, Timeframe, OHLC under mouse, Spread, Market Status,
Visible Bars, Start, End. Advanced optional: Zoom Level, FPS, Loaded
Candles, Provider Name, Cache Status. Adaptive: large chart -> full;
medium -> compact; small -> minimal. Minimal: Symbol, Timeframe, Spread.
Refresh only when data/state changes.

SOURCE CONFLICT RESOLUTION: An older summary contains Auto Hide /
Minimal / Expanded. The detailed finalized HUD decision is
authoritative: HUD remains visible, compact and adaptive. Auto Hide is
superseded unless explicitly reopened.

[FINAL HIGH-LEVEL] Types: TrendLine, Rectangle, Arrow, Text, Fibonacci,
Measure. Lifecycle: Create -> Select -> Edit -> Move -> Resize -> Clone
-> Lock -> Hide -> Delete -> Serialize -> Template. Rules: Selectable,
Movable, Resizable, Serializable, Theme Aware, Template Aware, Undo
Aware. Hit testing required.

[FINAL HIGH-LEVEL] Indicator Base, Inputs, Outputs, Rendering. Must
respect Data/Rendering contracts.

============================================================ 18 —
NAVIGATOR ============================================================

[FINAL] Optional Analysis Module, not permanent main-layout UI. Default:
Hidden.

Level 1: Wheel Zoom, Pan, normal viewport navigation. Level 2: Go To
Date, Go To Candle, Go To Time, Go To Latest; Home=latest;
Ctrl+G=navigation dialog; Ctrl+Home=latest market position. Level 3:
Optional Navigator Panel.

Panel: bottom of chart, 8%–12% chart height, Mini Chart/Mini Map,
Visible Range Box, Range Statistics, Current Position. Visible Range Box
represents current viewport/zoom range and is draggable. Overview shows
entire history/dataset with current visible range. Auto Hide enabled for
optional panel after invocation. Performance: simplified rendering,
reduced detail, independent cache. Main rule: Navigator never
permanently reduces main chart space.

============================================================ 25 —

[FINAL] Virtual Rendering, Object Pooling, Viewport Rendering,

refreshes only when required. Data/rendering remain isolated.

    ├── A stage is complete only when implementation, dependencies,

    │   calculations, and verification.

    ├── Downstream modules must consume established contracts.
    ├── Do not use temporary downstream logic to compensate for
