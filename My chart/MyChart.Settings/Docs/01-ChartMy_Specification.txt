- Corner radius: 4px

  Applies heavy settings only (visible.candles, fps.limit, gpu.acceleration, buffer.size)
- OK:
  Saves all settings + closes panel
- Cancel:
  Closes panel without saving
- Reset:
  Restores all settings to defaultValue

SECTION 4 — BEHAVIOR MODEL (Events & Logic)
-------------------------------------------

Immediate Behavior:

OnApply Behavior:
- visible.candles
- fps.limit
- gpu.acceleration
- anti.aliasing
- buffer.size
- engine.mode

Dependencies:
- show.grid = false → disable all grid settings
- show.wicks = false → disable wick.thickness
- gpu.acceleration = false → disable anti.aliasing
- display.type = area → enable area.background
- hud.items empty → disable hud.position
